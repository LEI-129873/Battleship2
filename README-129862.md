# Qodana – Long Parameter List

| Cheiro | Inspeção no IDE | ID | Métrica / limiar | Limitações |
|---|---|---|---|---|
| Long Parameter List | Method with too many parameters | `ParametersPerMethod` (opção `m_limit`) | nº de parâmetros > 5 | Limiar absoluto, não relativo ao sistema; não reporta métodos com super-método; o livro não tem estratégia para este cheiro |

## Reflexão

O gate detetou o método de 9 parâmetros em `Game.java` (limite 5) e passou depois de o refatorar com *Introduce Parameter Object*. Houve um falso negativo inicial: com o ID `MethodWithTooManyParameters` o gate ficou verde sem detetar nada, e só `ParametersPerMethod` funcionou. O limiar é absoluto, por isso métodos com exatamente 5 parâmetros, não são reportados.
